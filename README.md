# MATLAB Programming Lab

A collection of MATLAB programming laboratory exercises completed as part of my B.Tech coursework at **Gati Shakti Vishwavidyalaya**.

This repository contains MATLAB scripts developed to explore programming fundamentals, mathematical computations, numerical methods, and engineering-oriented problem-solving.

## 📚 Topics Covered

- MATLAB Fundamentals and Syntax
- Variables, Arrays and Matrices
- Mathematical and Matrix Operations
- Conditional Statements and Loops
- Functions and Script Files
- Data Visualisation and Plotting
- Numerical Computations
- Engineering Applications

*Note: Topics may vary depending on the individual laboratory exercises.*

## 🛠️ Technologies Used

- MATLAB
- MATLAB Editor and Command Window

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/AnshulPareek/MATLAB-Programming-Lab.git
```

2. Open MATLAB.
3. Navigate to the downloaded repository directory.
4. Open the desired `.m` file.
5. Run the script using the Run button or the Command Window:

```matlab
run('filename.m')
```
